Kodu artıq təkcə insanlar yazmır

GitHub 28 oktyabr, çərşənbə günü Universe konfransında illik Octoverse hesabatını açıqlayıb. Hesabat 1 oktyabr 2025 - 30 sentyabr 2026 dövrünü əhatə edir. Bu müddətdə platformada 34,3 milyard commit edilib, 1,3 milyard pull request (gündə təxminən 3,5 milyon) birləşdirilib. Ən diqqətçəkən rəqəm agentlərlə bağlıdır: martda kod dəyişikliyi təkliflərinin təxminən 17%-i süni intellekt agentinin qaralaması ilə başlayırdısa, sentyabrda bu pay 40%-i keçib. GitHub bu rəqəmin minimum olduğunu, çünki bütün agentləri aşkar edə bilmədiyini qeyd edir.

Platformada 225 milyondan çox proqramçı var. ABŞ (38,3 mln) və Hindistan (32 mln) liderdir, ardınca Çin (12,4 mln) və Braziliya (10,2 mln) gəlir. TypeScript ən populyar dil olaraq qalıb, Python ikinci, JavaScript üçüncüdür, Rust isə bir ildə təxminən iki dəfə böyüyüb. Eyni gün GitHub hər tapşırıq addımı üçün uyğun AI modelini avtomatik seçən Copilot Fusion sistemini də təqdim edib.
